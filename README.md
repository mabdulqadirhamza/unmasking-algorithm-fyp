🕵️‍♂️ Unmasking Algorithm

Unmasking Algorithm is a detective-themed puzzle game where players step into the shoes of a detective tasked with solving a complex theft case inside a police station. The game combines investigative storytelling with algorithm-based problem solving to create an engaging learning experience.

🎮 Game Overview

A valuable item has been stolen, and the suspects are many. As the detective, you must question characters, analyze clues, and apply logical thinking to uncover the truth behind the crime.

Each level of the game is inspired by a different search algorithm, turning abstract computer science concepts into interactive gameplay challenges.

🧠 Algorithms Featured

Linear Search 

Binary Search 

Array Indexing 


🧩 Gameplay Features

Story-driven detective gameplay

Logic puzzles based on real search algorithms

Progressive difficulty across multiple levels

Interactive dialogues and clue collection

Step-by-step investigation leading to the final reveal

🎯 Objective

Use your analytical skills and algorithmic thinking to connect the dots, identify the real culprit.

🚀 Educational Value

Unmasking Algorithm helps players:

Understand fundamental search algorithms

Apply logical reasoning in real-world scenarios

Learn through interactive storytelling and gameplay
